# Agent Skills

A collection of skills for AI coding agents. Skills follow the [Agent Skills](https://agentskills.io/) format.

## Install

```bash
npx skills add paulpan05/openrouter-multimodal-skill
```

## Available Skills

### openrouter-multimodal

Generate images, video, audio (TTS/STT), and process multimodal content via [OpenRouter's](https://openrouter.ai) unified API with a single API key.

**Use when:** Generating images, creating video, text-to-speech, speech-to-text, or sending multimodal inputs (images, PDFs, audio, video) to AI models.

**Prerequisites:** `OPENROUTER_API_KEY` — get one at [openrouter.ai/settings/keys](https://openrouter.ai/settings/keys)
